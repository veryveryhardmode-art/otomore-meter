一度作れば、ホーム画面のアイコンをタップするだけで、今の音量でこのページが開きます。音量を変えたら、もう一度タップしてください。

  1. 「ショートカット」アプリを開き、右上の「＋」を押す
  2. 「アクションを検索」で デバイスの詳細を取得 を追加し、青い「デバイス名」をタップして 現在の音量 に変える
  3. URL アクションを追加し、下のURLを貼り付ける。続けて、キーボードの上に出る「デバイスの詳細」を押して、URLの最後に入れる
  4. URLを開く アクションを追加する
  5. 画面上部の名前を 音漏れメーター にする（「音量を読み直す」ボタンがこの名前で呼び出します）
  6. 名前の横の「⌄」→「ホーム画面に追加」

同じ目盛りでの鳴りやすさ

同じ音量の目盛りでも、ほかのイヤホンより明らかに大きく聞こえるなら「大きめ」。

使えるのは有線イヤホンのマイクですBluetoothイヤホンはマイクを使うと通話モードに切り替わり、イヤホン内蔵のエコーキャンセルが流している音を打ち消すため、音漏れを測れません。AirPodsなどはiPhoneアプリ版（iPhone本体のマイクで測ります）か、推定モードを使ってください。
  1. マイク付きの有線イヤホンを挿し、両耳にしっかり着ける
  2. 音量はふだん聴いている目盛りにして、測定中は変えない
  3. 周りの音 → テスト音（マイクは垂らしたまま）→ テスト音（マイクを耳の横へ）の順に測ります。全部で約25秒

周りの音の大きさを基準にマイクの感度を合わせます。静かな部屋で測るのがいちばん正確です。

上ほど静かで、音漏れに厳しい場面です。タップすると内訳を表示します。

    内訳

    周りの音隣の人の耳に届く漏れ音（色は目立ち具合）

    計算のしかた
    • 耳に届く音は、最大音量で約100dB（ヨーロッパの規格EN 50332の上限）とし、音量の段階はAirPodsで実測された10%ごとの値（headphonesaddict）で dB に換算しています。
    • イヤホンの種類ごとに、帯域（125Hz〜8kHz）別の「耳から10cmへ漏れる量」を目安値で持っています。高い音ほど漏れやすい設定です。値は、静かな部屋でAirPods Pro・有線イヤホン・骨伝導を20cmと1mで聞き比べた公開記録（アイテム手帳）に合うよう補正しています。
    • 10cmから隣の人の耳までは、距離が2倍で約6dB下がる計算に、車内や室内の反響ぶんを少し加えています。
    • 帯域ごとに「隣の人の耳に届く漏れ音」と「周りの騒音」を比べ、いちばん目立つ帯域で判定します。騒音より12dB以上小さければ聞こえない、6dB以上小さければほぼ気づかれない、騒音を超えると気になる、8dB以上超えて歌やメロディの帯域（500Hz〜2kHz）も聞こえていれば曲までわかる、としています。
    • 場面の騒音のうち、新幹線・バスの車内の約70dB、書店の約50dB、図書館の約40dBは名古屋市「騒音の目安」をもとにしています。ほかは目安値です。
    • 実測モードは、周りの音でマイクの感度を合わせ、マイクの位置を変えた2回の差から電気的な回り込みを取り除いて、耳から10cmの漏れ音を求めます。
    • どちらのモードも誤差は±5dB程度です。判定は目安として使ってください。
